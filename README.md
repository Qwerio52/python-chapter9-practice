# 第9章 类的运算、模块和程序包
## 一、知识点总结
### 1. 面向对象
1. **类与实例**：类是封装属性和方法的模板；实例是根据类创建出来的对象。
2. **继承**：子类继承父类，复用父类代码；子类可以新增属性、新增方法、重写父类方法，使用 `super()` 调用父类构造。
3. **类方法 @classmethod**：第一个参数为 `cls`，属于类本身，不需要创建实例就可以直接调用。
4. **运算符重载**：重写魔术方法 `__add__`、`__sub__`、`__mul__`、`__truediv__`，让自定义类的对象支持 `+ - * /` 运算。

### 2. 模块与程序包
- **模块(module)**：单个 `.py` 文件，存放类、函数、变量，通过 `import` 导入。
- **程序包(package)**：包含 `__init__.py` 的文件夹，用来管理多个模块，实现代码分层封装。
- **封装**：把数据和操作数据的方法打包在一起，对外只提供调用接口，提升代码复用性、可读性。

## 二、习题解题思路
1. **9.1 图书馆系统**
图书类：书名、作者、ISBN、是否可借；方法：借书、还书、检查是否可借。
2. **9.2 银行账户管理**
父类BankAccount：存款、取款、查询余额；子类SavingsAccount储蓄账户计息；子类CheckingAccount支票账户支持透支。
3. **9.3 简易计算器**
使用`@classmethod`实现类方法，接收字符串表达式完成四则运算，无需实例化。
4. **9.4 学校成员管理**
父类SchoolMember（姓名、年龄）；Teacher子类：授课；Student子类：学习。
5. **9.5 购物车管理系统**
商品类保存名称价格；购物车实现添加、删除商品、折扣总价计算。
6. **9.6 天气查询工具**
基类预留天气查询、预报接口，不同城市作为子类分别实现。
